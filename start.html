# ✨ Sia's Adventure ✨ A magical 11+ preparation adventure game designed for Sia. ## Vision Sia's Adventure turns learning into a fantasy adventure. Players learn: - Maths - English Grammar - Punctuation - Spelling - Verbal Reasoning - Non-Verbal Reasoning while exploring magical worlds with: 🧙‍♂️ Wizzy the Wizard 🦉 Hootie the Owl 🐇 Hop the Rabbit --- ## Technology Built with: - HTML5 - CSS3 - Modern JavaScript (ES6) - JSON question databases - Browser Local Storage Designed to work: - Offline - Without installation - On laptop - On tablet/iPad in future --- ## Current Version Version 0.1 - Foundation Features: - Project structure - Start screen - Navigation - Save system foundation --- ## Future Features - Question engine - 600+ questions - Adaptive learning - XP system - Levels - Treasure chests - Achievements - Daily challenges - Progress dashboard - Online version --- ## Characters ### 🧙‍♂️ Wizzy Friendly wizard and teacher. ### 🦉 Hootie Helpful owl who provides hints. ### 🐇 Hop Celebration rabbit who rewards progress. --- Created for Sia ❤️
